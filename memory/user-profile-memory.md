# 用户画像记忆规则

## 应记录

- 目标领域
- 当前基础水平
- 5-12 天目标
- 应用场景
- 每日可投入时间
- 偏好的输出格式
- 偏好的 Agent 工作风格
- 已完成的实战任务
- 用户反复犯错的判断点

## 记录格式

```yaml
target_domain:
baseline_level:
adaptive_learning_goal:
business_context:
daily_time_budget:
preferred_output:
preferred_agent_style:
known_weaknesses:
completed_tasks:
updated_at:
```

## 更新时机

- 用户完成一次测试后。
- 用户明确纠正自己的目标或偏好后。
- 用户暴露出稳定薄弱点后。
- 用户完成一个实战交付物后。
