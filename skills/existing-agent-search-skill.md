# Skill: 已有 Agent / 工具 / 资料复用搜索

## 适用场景

在开发领域专家包前，判断是否已有可复用的 Agent、Skills、RAG、GitHub 项目、课程、数据库或工具链。

## 输入要求

- 目标领域
- 目标平台
- 预期功能
- 是否允许开源项目
- 是否需要商业工具

## 执行流程

1. 搜索 GitHub 项目。
2. 搜索 Claude Skills、OpenAI GPT / Assistants 思路、MCP 工具。
3. 搜索 LangChain、LlamaIndex、CrewAI、AutoGen、OpenHands 类项目。
4. 搜索行业专用 AI 工具、公开 prompt、workflow、template。
5. 搜索相关课程、数据集、知识库。
6. 评估复用性、集成难度、维护状态和风险。

## 输出格式

```markdown
# 可复用方案评估

| 名称 | 链接 | 类型 | 技术栈 | 维护状态 | 可复用部分 | 优点 | 缺点 | 是否采用 |
|---|---|---|---|---|---|---|---|---|

## 推荐采用

## 不建议采用

## 需要二次验证
```

## 质量标准

- GitHub 项目必须记录 stars、最近更新时间或维护状态。
- 商业工具必须记录价格和数据边界，如果可得。
- 不得只列链接，必须说明能替代本套件哪一部分。

## 失败处理

如果找不到可复用方案，说明检索范围，并给出自建理由。
