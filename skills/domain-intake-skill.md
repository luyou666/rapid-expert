# Skill: 领域启动访谈

## 适用场景

用户第一次进入某个新领域，或目标、基础、实战场景不清楚时调用。

## 输入要求

- 用户想研究的领域
- 当前基础
- 业务场景
- 可投入时间
- 目标平台
- 风险边界

## 执行流程

1. 使用 `system/intake-questions.md` 询问用户。
2. 判断是否涉及高风险领域。
3. 如果用户表达“想成为某领域专家”，先确认了解程度；低基础用户先获得一句话定义、3 个最小词、概念比喻和简单案例，不直接进入复杂任务。
4. 根据领域难度、用户基础、每日投入和实战目标，选择 5 / 7 / 9 / 12 天路线。
5. 生成用户需求画像。
6. 输出下一步执行计划，并主动追问一个用于收窄目标的问题。

## 输出格式

```markdown
# 启动画像

## 目标领域
## 用户基础
## 实战目标
## 建议学习天数
## 风险等级
## 是否需要联网
## 是否需要搜索可复用方案
## 目标平台
## 下一步任务
```

## 质量标准

- 不跳过风险判断。
- 不默认用户有基础。
- 学习天数必须解释原因。

## 失败处理

如果用户没有给出领域，先让用户选择一个业务场景，再反推候选领域。
