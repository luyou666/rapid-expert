# Skill: 商业模式分析

## 适用场景

分析公司、产品、项目或创业方向如何赚钱、成本在哪里、为什么客户愿意付费。

## 输入要求

- 公司 / 产品 / 项目名称
- 目标客户
- 收入模式
- 可用资料

## 执行流程

1. 描述客户和痛点。
2. 拆解收入来源。
3. 拆解成本结构。
4. 判断获客、交付、留存、复购和扩张逻辑。
5. 识别关键假设和最脆弱环节。
6. 对照竞品和替代方案。

## 输出格式

```markdown
# 商业模式分析

## 客户和痛点
## 收入来源
## 成本结构
## 关键资源
## 增长机制
## 脆弱环节
## 与竞品差异
## 需要验证的假设
```

## 质量标准

- 不能只写“市场空间大”。
- 必须说明客户为什么现在付费。
- 必须指出至少 3 个待验证假设。
