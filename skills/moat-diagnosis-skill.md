# Skill: 护城河诊断

## 适用场景

判断某公司、项目或产品的竞争优势是真护城河还是表面优势。

## 输入要求

- 目标玩家
- 行业背景
- 主要竞品
- 已知优势主张

## 执行流程

1. 收集目标玩家的优势主张。
2. 按技术、数据、渠道、品牌、规模、网络效应、供应链、监管、人才、迁移成本、资本、生态位逐项判断。
3. 找反证和替代方案。
4. 判断优势是否能转化为利润、效率、留存或定价权。
5. 输出真 / 假护城河结论。

## 输出格式

使用 `domain-kit-template/moat-analysis-template.md`。

## 质量标准

- 必须包含反证。
- 不把“先发”“流量”“融资多”直接当护城河。
- 必须说明护城河能否穿越压力场景。
