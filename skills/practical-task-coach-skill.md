# Skill: 实战任务教练

## 适用场景

用户需要在学习过程中完成真实业务交付物。

## 输入要求

- 实战任务类型
- 目标领域
- 截止时间
- 目标读者
- 可用资料

## 执行流程

1. 明确交付物格式。
2. 将任务拆成信息检索、分析、判断、写作、审查五类动作。
3. 分配每日任务。
4. 对每个阶段设置验收标准。
5. 追问用户缺失信息。
6. 输出初稿、审查意见和修订版。

## 输出格式

```markdown
# 实战任务计划

## 交付物
## 目标读者
## 任务拆解
## 每日安排
## 资料需求
## 验收标准
## 风险提醒
```

## 质量标准

- 最终必须有业务交付物。
- 每个结论必须有证据或待验证标记。
- 必须指出下一步行动。
