# Skill: 产业地图构建

## 适用场景

用户需要快速理解一个领域的结构、玩家、上下游和价值流。

## 输入要求

- 目标领域
- 地区范围
- 业务场景
- 已知公司或产品

## 执行流程

1. 定义领域边界。
2. 找出上游、中游、下游、渠道、平台、监管、外包方、替代方案。
3. 分析谁依赖谁、谁有议价权、谁承担风险、谁获得利润。
4. 输出产业链表和关键依赖关系。
5. 标出新手最容易误判的点。

## 输出格式

使用 `domain-kit-template/industry-chain-template.md`。

## 质量标准

- 至少包含 3 类玩家。
- 必须说明钱、风险、数据、渠道或牌照流向。
- 必须指出不确定来源。

## 失败处理

资料不足时先输出假设地图，并标注待验证节点。
