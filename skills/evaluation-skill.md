# Skill: 能力验收

## 适用场景

阶段学习完成后，判断用户是否已经能借助 AI / Agent 参与目标领域业务。

## 输入要求

- 用户学习记录
- 目标领域
- 实战交付物
- 测试结果

## 执行流程

1. 检查基础概念。
2. 检查术语和黑话。
3. 检查产业链拆解。
4. 检查护城河和竞品判断。
5. 检查风险识别。
6. 检查资料检索和证据分级。
7. 审查实战交付物。
8. 给出通过 / 有条件通过 / 未通过。

## 输出格式

```markdown
# 能力验收报告

## 结论
## 已达标能力
## 未达标能力
## 证据
## 主要错误
## 需要补课的模块
## 是否可以参与业务
## 建议参与边界
```

## 质量标准

- 不因用户完成学习天数就自动判定通过。
- 必须基于具体交付物和测试表现。
- 必须说明用户适合参与哪些业务、不适合独立负责哪些判断。
