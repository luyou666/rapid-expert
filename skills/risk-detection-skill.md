# Skill: 风险识别

## 适用场景

识别业务方案、行业机会、投资判断、产品方案中的法律、合规、安全、伦理、商业和执行风险。

## 输入要求

- 方案或判断文本
- 目标领域
- 地区范围
- 用户想执行的动作

## 执行流程

1. 判断是否高风险领域。
2. 提取方案中的关键行动。
3. 标注法律、合规、安全、伦理、隐私、财务、声誉、执行风险。
4. 区分可接受风险、需专业确认风险、禁止执行风险。
5. 给出安全替代方案。

## 输出格式

```markdown
# 风险识别

| 风险点 | 类型 | 严重性 | 证据 | 建议 |
|---|---|---|---|---|

## 禁止执行事项

## 需要专业人士确认的问题

## 合规替代方案
```

## 质量标准

- 不输出违规操作细节。
- 高风险内容必须提示专业确认。
- 必须给出安全替代方向。
