# Skill: 急速专家生成器

Legal and safety disclaimer: this skill is for learning, research, source organization, and workflow assistance only. It does not provide legal, financial, medical, psychological, cybersecurity, chemical safety, biosafety, tax, accounting, audit, compliance, or regulatory advice. High-risk decisions must be confirmed by qualified professionals.

Use this skill when a user wants to rapidly learn any business, industry, technical, or regulated domain and produce a practical deliverable with AI assistance.

## What This Skill Does

This skill turns a vague learning goal into a domain expert learning kit. It must first interview the user, then build a 5-12 day execution plan based on domain difficulty, user baseline, daily time budget, and final business task.

## Required First Step

Do not generate the full kit immediately. First ask the intake questions from the local bundled file:

`knowledge/intake-questions.md`

Then produce:

- target domain
- baseline level
- practical goal
- risk level
- recommended duration: 5, 7, 9, or 12 days
- whether fresh web research is required
- whether existing agents/tools/projects should be searched

## Workflow

1. Run domain intake.
2. Select learning duration using `knowledge/adaptive-learning-protocol.md`.
3. Search for fresh sources and reusable projects when allowed.
4. Build domain map using the templates from the root package when available.
5. Use the root package `skills/` to run research, analysis, risk detection, and evaluation when available.
6. Produce platform-specific deliverables.

## Safety

Follow all files in `safety/`. In high-risk domains, provide learning support, risk identification, and professional confirmation checklists only.

## Output Standard

Every business conclusion must identify:

- source
- date
- evidence strength
- fact / inference / experience judgment / unknown
- next verification step
