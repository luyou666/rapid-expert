# Intake Questions

Before generating a domain kit, ask:

1. What domain should we target?
2. What is the user's current baseline?
3. What practical task should be completed within 5-12 days?
4. Which scenario applies: investment research, startup validation, job search, consulting, product development, or another?
5. Does the domain involve high-risk areas such as medical, legal, finance, cybersecurity, chemical safety, privacy, minors, or criminal risk?
6. Is fresh web research allowed?
7. Should existing agents, skills, RAG projects, GitHub repos, courses, and datasets be searched first?
8. Which target platform is required: Claude Code, Hermes Agent, OpenClaw / OpenHands, or generic Markdown?
9. How much time can the user spend each day?
10. What is the acceptance criterion for business participation?
