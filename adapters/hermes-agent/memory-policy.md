# Hermes Memory Policy

## Store

- target_domain
- baseline_level
- business_goal
- learning_days
- daily_progress
- weak_points
- completed_deliverables
- accepted_risk_boundaries

## Do Not Store

- sensitive identity data
- unverified personal claims
- medical / legal / financial private details unless explicitly needed for the current task
- unsafe operational instructions

## Update Trigger

- after intake
- after each daily evaluation
- after final practical task
- after user changes goal
