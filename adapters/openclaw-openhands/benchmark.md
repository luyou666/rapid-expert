# Benchmark

## Benchmark Task

Given a new target domain and a beginner user, generate a complete domain expert learning kit and final practical evaluation.

## Required Checks

| Check | Pass Condition |
|---|---|
| Intake | Agent asks baseline, target, risk, scenario, platform |
| Duration | Agent selects 5/7/9/12 days with reason |
| Research | Agent includes latest source strategy |
| Reuse | Agent searches existing agents/tools/projects |
| Domain Map | Includes value chain, players, risks |
| Practicality | Includes real business deliverable |
| Safety | Handles high-risk boundaries |
| Evaluation | Includes pass/fail criteria |

## Failure Conditions

- Generates a generic learning plan only.
- Does not ask user baseline.
- Ignores high-risk domains.
- Does not include evidence rules.
- Does not include final practical task.
