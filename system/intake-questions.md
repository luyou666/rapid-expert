# 启动访谈问题

Agent 在开始生成任何领域包前，必须先问用户以下问题。问题可以一次性提出，也可以分两轮提出，但不得跳过高风险和验收问题。

## 核心问题

1. 你要进入或研究的具体领域是什么？
2. 你目前对这个领域的了解水平如何？可选：完全 0 基础 / 听过概念 / 做过简单调研 / 有相关项目经验 / 有从业经验。
3. 你希望在 5 到 12 天内完成哪类实战任务？可选：投资研究 / 创业验证 / 求职面试 / 咨询报告 / 产品开发 / 业务拓展 / 内部培训 / 其他。
4. 你希望最终产出什么？例如行业报告、竞品矩阵、商业模式拆解、岗位面试包、产品需求假设、投资备忘录。
5. 这个领域是否可能涉及医疗、法律、金融投资、心理诊断、化工安全、网络安全、隐私数据、未成年人、政治敏感或其他高风险内容？
6. 是否允许 Agent 联网检索最新资料、政策、新闻、公司动态和开源项目？
7. 是否需要优先搜索已有 Agent、Skills、RAG、GitHub 项目、课程、行业数据库，判断能否复用？
8. 你偏好的输出平台是什么？Claude Code、Hermes Agent、OpenClaw / OpenHands，还是通用 Markdown？
9. 你每天大约能投入多长时间？30 分钟 / 1 小时 / 2 小时 / 半天 / 全天。
10. 你希望 Agent 更像老师、研究助理、项目经理，还是实战教练？
11. 你最担心的失败是什么？学不懂、资料不可靠、无法落地、风险误判、时间不够，还是其他？
12. 你认为“通过验收”的最低标准是什么？

## 访谈输出格式

```markdown
# 用户需求画像

## 目标领域

## 当前基础

## 5-12 天目标

## 实战场景

## 目标交付物

## 风险等级

## 是否联网

## 是否搜索可复用方案

## 目标平台

## 每日投入时间

## 验收标准

## Agent 工作风格
```
