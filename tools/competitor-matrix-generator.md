# Tool Spec: competitor_matrix_generator

## 目标

生成公司、产品或项目的竞品矩阵。

## 输入

```json
{
  "domain": "目标领域",
  "players": ["玩家A", "玩家B"],
  "dimensions": ["客户", "价格", "渠道", "技术", "数据", "合规", "护城河"]
}
```

## 输出

| 玩家 | 客户 | 定价 | 渠道 | 技术 | 数据 | 合规 | 护城河 | 风险 |
|---|---|---|---|---|---|---|---|---|

## 质量要求

- 每个维度必须标注来源或待验证。
- 不知道就写“待验证”，不得补编。
